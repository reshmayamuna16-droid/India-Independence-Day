# India@80 – Independence Day Web Page

**India@80** is a creative and responsive Independence Day website built using **HTML5 and CSS3** to celebrate India's journey of freedom, unity, diversity, and progress.

The project was created as part of an **HTML & CSS Coding Contest by Credo Systemz**, with a focus on semantic HTML, creative CSS styling, responsive design, animations, and an engaging user experience.

## ✨ Features

* 🇮🇳 Indian Tricolor-inspired design
* 🔵 Custom Ashoka Chakra with **24 rotating spokes**
* 🕊️ Freedom Fighters section featuring Indian independence leaders
* 🖼️ Image gallery showcasing India's culture and heritage
* 🎨 Creative tricolor gradients and visual effects
* ✨ CSS hover effects and animations
* 📱 Fully responsive layout for different screen sizes
* 🚩 Custom mini Indian flags created using HTML & CSS
* 🌐 Navigation between different sections of the webpage
* 🔖 Custom Indian flag favicon
* ♿ Semantic HTML5 structure for better accessibility and organization

## 🛠️ Technologies Used

* **HTML5** – Semantic structure and webpage content
* **CSS3** – Styling, animations, responsive design, gradients, and hover effects

## 🎯 Project Objective

The goal of this project is to combine **web development and patriotic storytelling** into an interactive digital experience that highlights India's freedom struggle and celebrates the country's **Unity in Diversity**.

> 🇮🇳 *"Unity in Diversity • Freedom • Progress"*
